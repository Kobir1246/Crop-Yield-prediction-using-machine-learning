About the Project

The Crop Yield Prediction System is a machine learning-based web application developed to estimate crop yield (tonnes per hectare) across Bangladesh using agricultural, climatic, and geographical information.

The system uses a tuned XGBoost Regressor trained on the SPAS dataset, which contains 4,596 records covering 74 crop varieties across all 64 districts of Bangladesh and three agricultural seasons (Kharif 1, Kharif 2, and Rabi).

The model achieves strong predictive performance through careful feature engineering, categorical encoding, and hyperparameter tuning. The system also provides SHAP-based interpretability to help users understand which factors drive each prediction.

An Advanced Stacking Ensemble is also available, combining Random Forest, Gradient Boosting, XGBoost, and Ridge regression for improved accuracy. Both models include confidence intervals and detailed feature importance analysis.

This application is designed for researchers, agricultural analysts, extension officers, and policymakers who need quick, data-driven yield estimates for planning and decision-making.
